# CricketIQ
## IPL Match Prediction & Player Intelligence Analytics Platform

CricketIQ is an IPL analytics platform developed using Machine Learning, Data Analytics, and Streamlit. The project predicts IPL match winners and provides advanced player-based insights using historical IPL datasets.

---

# Features

- IPL Match Winner Prediction
- Random Forest Machine Learning Model
- K-Means Team Clustering Analysis
- Toss Impact Analysis
- Head-to-Head Team Comparison
- Team Performance Analytics
- Advanced Player Intelligence Engine
- Strike Rate Analysis
- Dismissal Weakness Detection
- Bowler Matchup Analysis
- Interactive Streamlit Dashboard

---

# Machine Learning Algorithms Used

## Random Forest Classification

Used for IPL match winner prediction based on:
- Team 1
- Team 2
- Venue
- Toss Winner
- Toss Decision

## K-Means Clustering

Used for grouping IPL teams based on historical performance and winning records.
